# Project Idea Planner

A beginner-friendly web app where you type a rough project idea in plain English and receive a clear, step-by-step build plan generated by AI.

## Stack

- **Frontend:** Next.js 14 (App Router) + Tailwind CSS
- **Backend:** Express.js + TypeScript
- **Database:** Supabase (configured, not used in v1)
- **AI:** Placeholder — swap in any provider in `backend/src/services/aiService.ts`

## Getting started

### Backend

```bash
cd backend
npm install
npm run dev
```

Runs on `http://localhost:3001`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:3000`

## Environment variables

See each app's `.env.example` for the required variables.
