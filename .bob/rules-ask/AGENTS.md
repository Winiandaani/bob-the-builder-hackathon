# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Non-obvious documentation context

- **`frontend/AGENTS.md` and `frontend/CLAUDE.md` are auto-generated by Next.js** (`next dev` recreates them). Do not treat them as hand-authored project documentation — they warn that this Next.js version may differ from training data.

- **`frontend/lib/supabaseClient.ts` exists but is entirely unused** — it is pre-wired setup for a future feature. No Supabase tables, queries, or auth flows exist anywhere in the codebase.

- **The plan file `project-idea-planner-plan.md` lives at the workspace root** (not inside the app folder) — it is the original build plan used to scaffold this project, with all 5 sub-tasks marked done.

- **All AI logic is in one file** — `backend/src/services/aiService.ts`. The model is `qwen/qwen3.8-27b` (not the originally planned `llama-3.3-70b-versatile`, which is unavailable on the current Groq key).

- **`PlanDisplay.tsx` strips `Step N:` prefixes** — the Groq model returns steps prefixed with `Step 1:`, `Step 2:` etc. The component removes these before rendering its own numbered circles, so the display is clean even if the model changes its format.
